# Contributing

Thanks for helping improve Lobbyte.

Before opening a pull request:

```bash
make fmt
make test
make check-npm
```

Keep changes focused, include tests for behavior changes, and preserve the client privacy boundary: Hook payloads, prompts, repositories, paths, code, and agent output must never be sent over the network.

By submitting a contribution, you agree that it is licensed under Apache-2.0 according to the contribution terms in the project license.
